# ROMs Helper

This is a CL tool (command line) which means that it works within your terminal. It's fully interactive, so you will not need to worry about anything technical.

#### Currently, the tool has this features (explained further in the "usage" section):

- Helps you delete duplicated or similar games between different consoles for curating your collection.
- Organizes your game names inside a text file, so you can browse your collection easily.
- Creates a statistics text file based on your games.
- Automatic renaming system for cleaning game names.
- Safety measures for renaming and deleting, being able to reverse changes.
