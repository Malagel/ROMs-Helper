# ROMs Helper

This is a CL tool (command line) which means that it works by typing commands to make the program do certain actions. The program will take your ROMs folder as input and do different tasks with it per instructions you give.

#### Currently, the tool  has this features (explained further in the "usage" section):

- Organize your ROMs inside a text file, so you can browse your collection easily.
- Create statistics based on your ROMs. 
- Help you delete duplicated or similar games between different consoles for curating your collection.
- Automatic renaming system for cleaning game names (e.g., removing region tags like (USA), (EUR), version numbers such as v1.2, duplicate spaces, and formatting symbols like `_`).
